# Instructions for Codex — TRUE QUEST

- Build a real playable browser game, not a static promotional page.
- Use Phaser 3 + TypeScript + Vite unless the repository already contains a sound working stack.
- The site URL must open straight into gameplay; no separate About/Features landing page.
- Original cartoon platform-adventure visual style, inspired by classic side-scrollers but never copying Mario or any protected game character/art.
- Keep the hero, environment, objects and UI visually consistent with `references/`.
- The provided PNGs are reference boards, NOT production sprite atlases. Never display the full board in gameplay or blindly slice it. Create clean separated assets and document any placeholders.
- Prioritize one polished playable DEX City level before building the remaining levels.
- Controls: keyboard on desktop, large touch controls on mobile, pause/mute, reduced-motion accommodation where practical.
- Provide real movement/physics, collisions, collectibles, NPC interaction, checkpoint/respawn, and portal/end trigger; no fake buttons.
- Use short educational dialogue. Verify project facts against https://true.foundation/. Clearly label planned $TRUE utilities as planned, not live.
- Show announced listing: October 15, 2026 at 18:00 CET on TRUE DEX, while noting launch details can change and linking the official source.
- No wallet connect, seed phrase, private key, token purchase, on-chain transaction, financial reward for playing, fake leaderboard, fake price/APY, or investment promises.
- External project links must be verified from the official site, not guessed.
- After each milestone, run the build, fix errors, state what was tested, and explain how the user can preview it.
- If art extraction quality is poor, use an explicitly labelled temporary original placeholder rather than claiming it is production art.
